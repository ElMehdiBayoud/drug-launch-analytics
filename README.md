# Optimizing Drug Launch Success with Prescriber Analytics

🎯 **Objective**  
Predict which prescribers are likely to adopt a newly launched drug within its first year, 
using pre-launch prescribing behavior and demographic data from the CMS Medicare Part D Prescriber dataset.

---

## 🧠 Project Summary
This notebook performs the full analytical workflow:
1. Data import, optimization, and cleaning  
2. Feature engineering (Adoption Lag, Early Adopter, behavioral ratios)  
3. Exploratory data analysis (distribution, specialties, states)  
4. Predictive modeling with Random Forest and Gradient Boosting  
5. Sequential Deep-Learning extension (LSTM)  
6. Interpretability (SHAP, feature importance)  
7. Business insights and future recommendations
